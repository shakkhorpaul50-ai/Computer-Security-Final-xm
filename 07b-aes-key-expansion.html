07B — Symmetric Deep-Dive

AES Key Expansion — Every Word Traced

FIPS-197 vector: how 2b7e1516 28aed2a6 abf71588 09cf4f3c becomes 11 round keys. Companion to 07.

Rules (AES-128: 4 words → 44 words)

# W0..W3 = cipher key columns. For i = 4..43: if (i mod 4 == 0): temp = SubWord(RotWord(W[i-1])) ⊕ Rcon[i/4] else: temp = W[i-1] W[i] = W[i-4] ⊕ temp RotWord(a,b,c,d) = (b,c,d,a) # 1-byte left rotate SubWord = S-box on each of the 4 bytes Rcon[j] = (2^(j-1) in GF(2^8), 0, 0, 0) → 01,02,04,08,10,20,40,80,1B,36 ...

W₀–W₃ (the key itself, column-wise)

W0 = 2b7e1516 W1 = 28aed2a6 W2 = abf71588 W3 = 09cf4f3c # K0 = W0‖W1‖W2‖W3 = the cipher key.

Round 1 words W₄–W₇ → K₁ (full trace)

# --- W4 (i=4, Rcon[1]=01000000) --- W3 = 09 cf 4f 3c RotWord = cf 4f 3c 09 SubWord (S) = 8a 84 eb 01 # S[cf]=8a S[4f]=84 S[3c]=eb S[09]=01 ⊕ Rcon[1] = 8b 84 eb 01 # 8a⊕01=8b, rest unchanged W4 = W0 ⊕ temp = 2b7e1516 ⊕ 8b84eb01 = a0fafe17 # 2b⊕8b=a0 7e⊕84=fa 15⊕eb=fe 16⊕01=17 ✓ # --- W5, W6, W7 (no Rot/Sub, just chain XOR) --- W5 = W1 ⊕ W4 = 28aed2a6 ⊕ a0fafe17 = 88542cb1 # 28⊕a0=88 ae⊕fa=54 d2⊕fe=2c a6⊕17=b1 W6 = W2 ⊕ W5 = abf71588 ⊕ 88542cb1 = 23a33939 # ab⊕88=23 f7⊕54=a3 15⊕2c=39 88⊕b1=39 W7 = W3 ⊕ W6 = 09cf4f3c ⊕ 23a33939 = 2a6c7605 # 09⊕23=2a cf⊕a3=6c 4f⊕39=76 3c⊕39=05 K1 = W4‖W5‖W6‖W7 = a0fafe17 88542cb1 23a33939 2a6c7605 ✓

Round 2 words W₈–W₁₁ → K₂ (full trace)

# --- W8 (i=8, Rcon[2]=02000000) --- W7 = 2a 6c 76 05 RotWord = 6c 76 05 2a SubWord = 50 38 6b e5 # S[6c]=50 S[76]=38 S[05]=6b S[2a]=e5 ⊕ Rcon[2] = 52 38 6b e5 # 50⊕02=52 W8 = W4 ⊕ temp = a0fafe17 ⊕ 52386be5 = f2c295f2 W9 = W5 ⊕ W8 = 88542cb1 ⊕ f2c295f2 = 7a96b943 W10 = W6 ⊕ W9 = 23a33939 ⊕ 7a96b943 = 5935807a W11 = W7 ⊕ W10 = 2a6c7605 ⊕ 5935807a = 7359f67f K2 = f2c295f2 7a96b943 5935807a 7359f67f (FIPS-197 ✓)

Rest of the schedule (structure, values to verify against)

Rounds 3–10 continue identically (Rcon 04,08,10,20,40,80,1B,36). Total 44 words → 11 keys K₀–K₁₀. Properties examiners love:

  • Each word depends on all previous key bytes — one key-bit flip avalanches through later round keys
  • Non-linearity comes only from the i mod 4==0 SubWord steps; the other 3/4 are linear XOR chains
  • Rcon breaks symmetry (otherwise W₄=W₀⊕f(W₃) patterns could slide)
  • AES-192 uses 6-word blocks with SubWord every 6th; AES-256 adds SubWord on i mod 8==4 too
Memorise
temp = Sub(Rot(prev)) ⊕ Rcon every 4th word; otherwise W[i]=W[i-4]⊕W[i-1]. Rcon = powers of 2 in GF(2⁸): 01 02 04 08 10 20 40 80 1B 36.
Exam one-liner: Show W₄ from W₀⊕(Sub(Rot(W₃))⊕Rcon) = a0fafe17, then chain — that single trace proves you understand the schedule.
