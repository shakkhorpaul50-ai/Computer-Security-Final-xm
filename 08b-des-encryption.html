S-box walkthrough — S1 fully, rest identically
B1=011000: outer 00=row 0, inner 1100=col 12. S1 row 0 = [14,4,13,1,2,15,11,8,3,10,6,12,5,9,0,7] → col 12 = 5 = 0101. B2–B8 each do the same row/column lookup in S2–S8 (6→4 bits), giving 32 bits total, then Permutation P shuffles them → 32-bit f(R₀,K₁).

What to memorise
IP gives L₀=CC00CCFF R₀=F0AAF0AA; Round 1 gives L₁=F0AAF0AA R₁=EF4A9CBB; final cipher 85E813540F0AB405. K₁=1B02EFFC7072, K₁₆=1B9616787196. If you can reproduce E⊕K₁=6117BAAB0A67 and the S1 lookup, you own DES.
Exam one-liner: Expand (E) → XOR key → S-boxes → P-permute → XOR left half; 16× with K₁…K₁₆, then IP⁻¹.
